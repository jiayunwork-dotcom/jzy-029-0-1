一维水驱的前缘走多快，不取决于当地饱和度的导数，而取决于从束缚水点向分流曲线做的那条切线。调用方给出油水粘度、束缚水饱和度 Swc、残余油 Sor，以及 Corey 相对渗透率的端点与幂次。服务先在可动区间里算出含水率分流函数 f(Sw)，再从 (Swc, 0) 向 f 做切线，切点饱和度 Swf 就是激波前缘；激波后方按 f 的导数给出稀疏波，得到无因次速度 ξ 上的饱和度剖面。范围限定在 Buckley–Leverett 分流与 Welge 作图，仅经 HTTP 提供物性档与剖面。

水相相对渗透率按 Corey：以可动水饱和度为底、幂次为 nw，再乘水相端点。油相同理，底是可动油、幂次 no、乘油相端点。流度是相对渗透率除以该相粘度。分流 f 等于水流度除以两相流度之和。Swc、Sor 不得为负，两者之和必须严格小于 1。粘度必须为正。Corey 幂次必须为正。端点相对渗透率落在 (0, 1]。可动区间之外 f 不得拿来做切线。

切点满足：切线斜率等于 f(Swf) 除以 (Swf 减 Swc)（束缚水处 f 取 0）。激波速度就取这条斜率。切点必须落在 Swc 与 1−Sor 的开区间内；做不出切线或切点落到端点上，剖面失败，不要用中点饱和度凑一条斜坡。末端 Sw 等于 1 减 Sor 时 f 必须为 1。激波后方是稀疏：ξ 等于当地 df/dSw，饱和度随 ξ 连续变化；前缘处不得改用当地导数代替切线速度——那样激波会偏慢，整条剖面超前或滞后。不要用中心差分把激波抹成不守恒的斜坡还当解析解。

水相对油的粘度比下降（流动性变有利）时，Swf 应升高、前缘变钝。只把 Sor 加大，末端饱和度左移，可动油变少。两相粘度相等且 Corey 幂次相同，f 在可动区间中点附近大致对称。物性可以登记成具名档，点名一档出剖面；也可以把参数写在当次请求里。剖面按调用方给出的 ξ 取样点返回 Sw，并带上 Swf、激波速度、切线斜率。

列出物性档时给出粘度、Swc、Sor、端点与幂次。启动后必须能对一组水驱参数求出落在可动区间内的 Swf，且切线斜率与 f(Swf)/(Swf−Swc) 对上；浏览器打开页面即能看到这组参数画出的分流曲线、那条切线与前缘位置。缺项、Swc 加 Sor 越界、粘度非正、切线无解，拒绝并说明原因。

浏览器打开即是一块可查看的剖面台：对当前物性档或当次参数，页面把含水率分流曲线 f(Sw) 画在可动区间上，叠上从 (Swc, 0) 向 f 所做的那条 Welge 切线，标出切点 Swf 与末端 1−Sor；另一块画出无因次速度 ξ 上的饱和度剖面，前缘处是竖直的激波、后方是稀疏波。改变粘度比或 Sor 后重新求解，曲线、切点与剖面随之更新，能一眼看出 Swf 升高、前缘变钝或末端左移。页面只做呈现，物性与切点计算仍由后端负责。

用 Python 3.12 与 FastAPI 对外提供 HTTP。物性档以本地文件保存。前端页面作为同一个服务内的静态资源随后端一起提供，不引入额外服务。镜像基于 python:3.12-slim 构建，一条 docker build 再 docker run 即可对外只暴露 HTTP，跑单容器。相对渗透率、分流函数、切点搜索、剖面取样分成不同模块，不要堆进同一个文件；前端页面与后端计算分开，页面不得自己另算切线。测试锁住：切点斜率等于 f(Swf)/(Swf−Swc)、末端 f 为 1、切点落在可动开区间、粘度比变有利则 Swf 升高、Sor 加大则末端左移、用当地导数冒充切线会被剖面位置卡住、Swc 与 Sor 之和越界被拒、粘度非正被拒、未知档名被拒。
